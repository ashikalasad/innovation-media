INNOVATION MEDIA – PROJECT EDIT/WORKFLOW UPDATE

1) Supabase Dashboard > SQL Editor > New Query
2) Open PROJECT_FEATURES_SQL.sql, copy all SQL and Run.
3) Extract this ZIP to a NEW folder (do not overwrite your previous folder).
4) Copy your working .env file into this folder.
5) Open CMD in this folder and run:
   npm install
   npm run dev
6) Open the localhost URL printed by Vite.
